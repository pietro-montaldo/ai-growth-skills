# Formula library

Every example hook below is invented to show a structure. The companies, numbers and results are made up. Never reuse them. Write in the user's voice with the user's real facts.

## The two-line structure

Many high-performing hooks share one shape:

**Line 1:** a bold claim, a number or a comparison. This stops the scroll.
**Line 2:** a practical promise for a specific audience. "Here is...", "This is how to...", "This is the setup...". This is the reason to click "see more".

The two lines sit on separate lines. They are not joined into one sentence. Together they deliver the primary value in under 140 characters.

```
Cold email is not dead. Your list is.
Here is how I rebuilt mine in one afternoon 👇
```

Two lines is the default. Some single-line hooks work well, mostly comparisons and callouts. Check the user's own best posts: if their winners follow a different shape, follow theirs.

## The formulas

The primary value stays the same across all 10 hooks. The formula changes how you deliver it.

### Bold Claim + Guide
Line 1 makes a strong, specific claim. Line 2 offers the guide.
```
Customer interviews are my best lead source
This is how I run them without sounding like a survey
```

### Simple Comparison
The ">" format. Short. Puts one thing above another for a specific audience.
```
10 customer calls > 100 survey answers
Here is the interview script I use with every new client
```

### The System Builder
Name the system you built, what it does, and what an agency would charge.
```
I built a weekly competitor report that runs while I sleep.
Agencies charge $3K a month for this.
```

### Social Proof + Event
A specific number of people plus what they signed up for.
```
212 agency owners signed up in 4 days for a free session on pricing retainers.
```

### Migration / Switch
A personal switch story with specific effort and tool names.
```
Last month I cancelled 4 marketing tools.
One spreadsheet and an AI assistant replaced all of them.
```

### The Giveaway
Give away something valuable. Anchor it to what others charge.
```
Consultants charge $5K to build this onboarding playbook.
I'm giving mine away for free.
```

### Callout + Correction
Call out a bad practice hard. Promise the fix. Caps and exclamation marks fit here, if the user writes that way.
```
"Just post every day" is BAD advice.
Here is what actually grew my account:
```

### Investment to Result
Stack the effort, then the result or availability.
```
300 hours of sales calls reviewed. 40 objections logged.
Turned into one 2-page cheat sheet.
```

### Behind-the-Scenes Build
Name what you built plus one measurable result.
```
I built a pipeline dashboard with zero code.
It shows every stuck deal before Monday's meeting.
```

### Combo Stack
A tool combination that produces an outsized result.
```
Google Sheets + an AI assistant + your call recorder = a sales coach that never sleeps
```

### Reverse Engineer
Turn research into a repeatable shortcut.
```
Reverse engineer your best customer's buying journey.
I turned 12 interviews into a 10-minute exercise.
```

## Character counts

LinkedIn cuts the post at "see more".
- **Safe zone: 140 characters.** Visible on every device, including mobile.
- **Desktop max: about 210 to 220 characters.** Visible on desktop only.
- Everything counts: letters, spaces, punctuation, emojis and line breaks.
- The script counts a line break as 1 character. On screen it takes more room, so leave a few characters of margin on two-line hooks.

The script tags each hook SAFE (140 or less), WARNING (desktop only, up to 220) or REJECT (too long).

## Output format

Hooks are shown without quotes, exactly as they would look on LinkedIn.

```
**Primary value:** [one sentence]

---

⭐ 1. [Bold Claim + Guide]
Customer interviews are my best lead source
This is how I run them without sounding like a survey
[97 chars] SAFE
> Why: specific claim plus a practical promise. The right reader self-selects.

2. [Simple Comparison]
10 customer calls > 100 survey answers
Here is the interview script I use with every new client
[95 chars] SAFE
> Why: the ">" format is fast to read. Line 2 says what's inside.

...
```

## Edge cases

- **No numbers available:** use Bold Claim + Guide, Callout + Correction or Simple Comparison. They don't need numbers.
- **Opinion post:** lean on Callout + Correction. Avoid Giveaway and Investment to Result.
- **A new tool or launch:** use Bold Claim + Guide or Simple Comparison.
- **"Just one hook":** write 3 anyway. Options build instinct.
- **The draft already has a strong hook:** say it works and why, then offer 3 alternatives to compare.
- **Primary value unclear:** ask. Don't guess.
