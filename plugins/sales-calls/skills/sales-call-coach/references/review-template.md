# Review template

The whole review is one file (or one Notion page if you asked for that). Not one per call. You should be able to read it top to bottom in 5 minutes.

## Title

`Sales call review YYYY-MM-DD to YYYY-MM-DD`, with the real start and end of the window.

One call only: `Call coaching: [Company] YYYY-MM-DD`.

## Layout

```markdown
# Sales call review YYYY-MM-DD to YYYY-MM-DD

## Week at a glance

- Sales calls coached: N
- Other external calls (delivery, network, unclear): N (listed at the bottom)
- Biggest strength: [one sentence]
- Biggest pattern to fix: [one sentence]

## Action items you owe prospects

- [ ] [Company] · [action] · by [date]
- [ ] ...

(Sorted by deadline, soonest first. "No deadline given" last.)

## Calls

### [Company] · YYYY-MM-DD · [length]

**Type:** [call type]
**Recording:** [link, if there is one]
**Attendees:** [first names and roles on their side]

#### Call basics

- Talk ratio: [X% you, Y% them, target Z]
- Longest monologue: [N seconds, topic, time]
- Questions: [N open, N leading]
- Buying signals: [N caught, N missed, list the missed ones]
- Pain before pitch: [yes, or no with the time]
- Next step: [specific, vague or none, quote it]
- Energy match: [only if there was a mismatch]
- Price vs value: [only if price came up]

#### Framework: [name]

[One sentence on why it fits.]

[Framework output from frameworks.md.]

#### Coaching

What you did well:
1. [Specific moment, with time]
2. ...

What to change next call:
1. [An action, not a label]
2. ...

#### Action items from this call

- [ ] You: [action] by [date]
- [ ] [Their first name]: [action] by [date]

---

## Other external calls

Listed, not coached:

- [Title] · YYYY-MM-DD · `client_delivery`, `peer_or_network` or `unclear`
- [Title] · YYYY-MM-DD · under 5 minutes, not coached
```

## Rules

- `##` for top sections, `###` for each call, `####` inside a call.
- A `---` line between calls so the file is easy to scan.
- Action items use `- [ ]` checkboxes so you can tick them off.
- At most 3 strengths and 3 changes per call. Pick the 3 that matter most.
- No closing summary. "Week at a glance" is the summary.
- No tables longer than 6 rows. No screenshots. No "this report was generated by" footer.
- No definitions of SPIN or MEDDIC. The name is enough.

## Notion

If you asked for Notion, use the same markdown. Title as above. Checkboxes become to-dos. Put it where you said; if you didn't say, ask once.

## Single call mode

Use the block from `### [Company]` down to "Action items from this call". In chat, or in a file if you prefer.
