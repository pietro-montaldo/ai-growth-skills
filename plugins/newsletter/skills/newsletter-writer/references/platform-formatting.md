# Platform formatting

Most newsletter editors are rich text editors, not raw HTML. So the draft is markdown plus a few markers you apply by hand when you paste it in.

## Markers used in the draft

| In the draft | What you do in your editor |
|---|---|
| `### Heading` | Format the line as a heading (H3 or the platform's section heading) |
| `**bold**` | Bold. Use for key labels, names and numbers. Don't bold everything. |
| `*italic*` | Italic. Good for event taglines and short quotes. |
| `[Divider]` | Insert the editor's divider or horizontal line |
| `[Button: "Text"] → link` | Insert a button with that text and link |
| `[Image: description]` | Upload that image here |
| `[Embed video: description] → link` | Use the editor's video embed |

Images: full width, real screenshots over stock photos, nothing text-heavy that can't be read on a phone, and never a screenshot that shows the full contents of the resource. Teaching editions need few or no images. Roundups benefit from a cropped preview of the main piece and one for an event.

## Platform notes

Check your own editor, because platforms change. As a guide:

- **Substack:** there is no separate preview text field. The subtitle doubles as the preview text, so write the preview line as the subtitle. Buttons, dividers and video embeds are in the editor toolbar.
- **Beehiiv:** has a subtitle and a separate preview text field. Use the preview line for preview text. The subtitle can carry the scope line.
- **Kit (formerly ConvertKit):** has a preview text field in the email settings. Buttons are a content block.
- **LinkedIn newsletter:** readers see the title, the cover image and the first lines. There's no preview field, so make the first line after the title do the preview line's job. Buttons don't exist: write the link as a short line of text ("Open the full guide: [link]"). Dividers and video embeds are limited, so a roundup reads better with clear headings.
- **Other platforms (Mailchimp, MailerLite, Ghost and similar):** look for a "preview text" or "preheader" field. If there isn't one, the first line of the body is what shows.

## Paste-ready delivery

When the draft is approved, hand it back as:

```
SUBJECT: [chosen subject line]
PREVIEW LINE: [preview line] (or SUBTITLE on Substack)

BODY:
[the edition, with the markers above]
```

Then, in one or two lines, list the markers to apply for your platform.
